# Search Console Checklist

1. Deploy Phase 3C to production.
2. Confirm the production homepage metadata, canonical URL, Open Graph image, and Twitter card.
3. Add the domain property for `jackdennehey.com` in Google Search Console.
4. Complete DNS verification through Porkbun.
5. Submit `https://jackdennehey.com/sitemap.xml`.
6. Inspect `https://jackdennehey.com/`.
7. Request indexing for the homepage.
8. Test the structured data with Google's Rich Results Test or Schema Markup Validator.
9. Test the Open Graph image in a social-card preview tool.
10. Recheck after Google recrawls the page.
